Guide : Google Maps API pour une application de livraison

Document de configuration — Projet YAA Delivery

Pourquoi Google Maps ?

Pour une application de livraison, Google Maps est la solution recommandée. C'est la plateforme utilisée par Uber, Bolt, Glovo et la quasi-totalité des applications de livraison dans le monde.

Étape 1 — Créer un compte Google Cloud

1.1  Aller sur Google Cloud Console

Rendez-vous sur : https://console.cloud.google.com

Connectez-vous avec un compte Gmail professionnel lié à l'entreprise.

⚠️ Important : Utilisez un compte Google que vous contrôlerez durablement. Si le titulaire du compte quitte l'entreprise, l'accès aux APIs peut être compromis.

1.2  Accepter les conditions d'utilisation

Lors de la première connexion, acceptez les conditions d'utilisation de Google Cloud.

Étape 2 — Configurer la facturation

💡 Google offre un crédit mensuel de 200 $ USD qui couvre largement les besoins d'une application en phase de démarrage. Vous ne payez que si vous dépassez ce crédit.

2.1  Créer un compte de facturation

  1. Dans le menu de gauche → "Facturation"
  2. Cliquez sur "Créer un compte de facturation"
  3. Renseignez le nom (ex : YAA Delivery), le pays, et ajoutez une carte bancaire internationale (Visa / Mastercard)

2.2  Estimation des coûts

APIPrixInclus dans le crédit gratuit

💡 Pour une application avec moins de 10 000 utilisateurs actifs par mois, le crédit de 200 $/mois couvre généralement la totalité des coûts.

Étape 3 — Créer un projet Google Cloud

  1. En haut de la console, cliquez sur le sélecteur de projet (à côté du logo Google Cloud)
  2. Cliquez sur "Nouveau projet"
  3. Nom du projet : YAA-Delivery
  4. Cliquez sur "Créer" et attendez quelques secondes
  5. Sélectionnez ce projet dans le sélecteur en haut
  6. Allez dans Facturation → Mes projets → associez-le à votre compte de facturation

Étape 4 — Activer les APIs

  1. Menu de gauche → "APIs et services" → "Bibliothèque"
  2. Recherchez et activez chacune de ces APIs en cliquant sur "Activer" :
  • Maps SDK for Android
  • Maps SDK for iOS
  • Places API
  • Geocoding API
  • Directions API
  • Distance Matrix API

Étape 5 — Créer les clés API

5.1  Clé pour Android

  1. Menu → "APIs et services" → "Identifiants"
  2. Cliquez sur "+ Créer des identifiants" → "Clé API"
  3. Cliquez sur "Modifier la clé" (icône crayon)
  4. Renommez-la : YAA Android Key
  5. Sous "Restrictions d'application" → sélectionnez "Applications Android"
  6. Ajoutez le nom du package et l'empreinte SHA-1 (à demander au développeur)
  7. Sous "Restrictions d'API" → cochez les 5 APIs listées à l'étape 4
  8. Cliquez sur "Enregistrer"

5.2  Clé pour iOS

Même procédure, avec ces différences :

  • Nom : YAA iOS Key
  • Restriction : "Applications iOS"
  • Bundle ID : à demander au développeur (ex : com.yaa.delivery)

5.3  Clé pour le serveur (optionnel)

  • Nom : YAA Server Key
  • Restriction : "Adresses IP" → ajouter l'IP du serveur backend

Étape 6 — Sécuriser les clés API

⚠️ Ne partagez jamais vos clés API publiquement. Ne les envoyez pas par email en clair, et ne les publiez jamais sur GitHub ou tout autre dépôt de code.

Configurer une alerte de budget

  1. Menu → "Facturation" → "Budgets et alertes"
  2. Cliquez sur "Créer un budget"
  3. Définissez un montant seuil (ex : 50 $) et votre adresse email
  4. Google vous alertera automatiquement si vos coûts approchent ce seuil

En cas de fuite d'une clé

Retournez sur la console → Identifiants → cliquez sur la clé concernée → "Regénérer la clé". L'ancienne clé sera immédiatement invalidée.

Étape 7 — Transmettre les informations au développeur

Une fois toutes les étapes terminées, transmettez les clés à votre développeur via un canal sécurisé (gestionnaire de mots de passe, message privé chiffré — pas par email ordinaire) :

Clé Android : AIzaSy...
Clé iOS     : AIzaSy...
Clé Serveur : AIzaSy... (si applicable)
⚠️ Le développeur intégrera ces clés dans les fichiers de configuration sécurisés de l'application. Ces clés ne doivent jamais apparaître dans le code source versionné (Git / GitHub).

Récapitulatif des étapes

  1. Créer un compte sur console.cloud.google.com
  2. Configurer la facturation (carte bancaire internationale)
  3. Créer un projet YAA-Delivery
  4. Activer les 6 APIs listées
  5. Créer 2 clés API (Android + iOS) et les restreindre
  6. Configurer une alerte de budget (ex : 50 $)
  7. Transmettre les clés au développeur de façon sécurisée
